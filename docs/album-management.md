# 相册管理功能说明

更新时间：2026-05-11

## 功能范围

- 相册创建者可以在首页相册卡片上修改相册名称。
- 相册创建者可以在首页相册卡片上删除相册。
- 非创建者不能修改或删除相册，前端不会显示“改名”“删除”按钮。
- 后端也会校验创建者权限，防止绕过前端直接调用接口。
- 删除相册只删除相册记录，不删除相册内原有照片/视频；媒体记录会按现有外键规则解除相册关联。

## API

### PUT /api/albums/:id

修改相册名称。需要登录，且只能由相册创建者调用。

请求体：

```json
{
  "title": "新的相册名称"
}
```

响应：

```json
{
  "message": "相册名称已更新",
  "album": {
    "id": 1,
    "user_id": 2,
    "title": "新的相册名称",
    "cover_url": "/uploads/cover.png",
    "created_at": "2026-05-11T00:00:00.000Z",
    "username": "user",
    "role": "user"
  }
}
```

常见错误：

| 状态码 | 说明 |
|------|------|
| 400 | 相册 ID 无效或相册名称为空 |
| 403 | 当前用户不是相册创建者 |
| 404 | 相册不存在 |

### DELETE /api/albums/:id

删除相册。需要登录，且只能由相册创建者调用。

响应：

```json
{
  "message": "相册已删除"
}
```

常见错误：

| 状态码 | 说明 |
|------|------|
| 400 | 相册 ID 无效 |
| 403 | 当前用户不是相册创建者 |
| 404 | 相册不存在 |

## 前端行为

- `Home.jsx` 根据 `album.user_id === currentUser.id` 判断是否显示“改名”“删除”。
- “改名”使用浏览器输入框输入新标题，成功后即时更新当前相册卡片。
- “删除”会二次确认，成功后从首页相册列表移除该相册。
- `AlbumCard.jsx` 接收 `onRename`、`onDelete` 和 `managing` props，负责展示创建者操作按钮和处理中状态。
